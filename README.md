# عقاري

موقع عربي متجاوب لتصفح العقارات، حفظ المفضلة، إدارة الإعلانات، ومقارنة تقديرات التمويل.

## التشغيل

1. ثبّت Node.js إصدار 20 أو أحدث.
2. فك ضغط المشروع وافتح الطرفية داخل مجلده.
3. شغّل `npm start` أو `node script.js`.
4. افتح http://127.0.0.1:3000 في المتصفح، واترك الطرفية مفتوحة.

لا توجد حزم إضافية تحتاج إلى تثبيت. فتح index.html مباشرة لا يشغّل خدمات الحسابات.

إذا كان المنفذ 3000 مستخدمًا، شغّل في PowerShell:

```powershell
$env:PORT=3001
node script.js
```

ثم افتح http://127.0.0.1:3001.

## الملفات

- index.html: الصفحات والنماذج.
- style.css: الهوية والتنسيق المتجاوب.
- script.js: خادم Node.js، الحسابات، ومنطق الواجهة.
- aqari-logo.png: شعار عقاري الأصلي المرفق.

## حدود النسخة

- العقارات والأسعار المعروضة بيانات توضيحية؛ التمويل تقديري وغير ملزم.
- الإعلانات والمفضلة محفوظة في المتصفح، ولا تنتقل بين الأجهزة ولا تُنشر للآخرين.
- تُنشأ بيانات الحسابات محليًا داخل private-data عند الاستخدام. لم تُضمَّن حسابات المستخدمين في هذه الحزمة.
- الجلسات محفوظة في ذاكرة الخادم، وإعادة تشغيله تتطلب تسجيل الدخول مجددًا.
- خدمة تأكيد البريد واستعادة كلمة المرور تتطلب إعداد خدمة البريد. التحقق الرسمي من فال غير مربوط بعد.
- الصور وخط الواجهة يحتاجان إلى اتصال بالإنترنت.
- هذه حزمة للتشغيل المحلي؛ لم يتم نشر الموقع على استضافة عامة.
